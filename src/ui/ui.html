How to use

Test mode:

  1. Open your form/test like you normally would.
  2. If you want to get question solved with AI, double click that question.
  3. Wait until it generates, could take up to 30 seconds on smarter models. (You can still generate answers for other questions in the same time)
  4. Done! Question selects or types itself.

Manual mode (desktop only):

  1. Open any website.
  2. If you want to ask AI about something, select some text, right click, and press "Ask Gemini AI" option.
  3. Wait until it generates, could take up to 30 seconds on smarter models.
  4. Done! Answer will show up in popup window at the bottom of the page. To close it - double click it.

Make sure you set up your Gemini API key first!
