# Solve my forms

Solve my forms is an open source extension for firefox to solve google forms tests with AI (Gemini API)

This extension is programmed by a human, only checking of the answers is AI. System prompt is written by me too, so it may contain grammatical errors.

Keep in mind that this extension is still a prototype and some options can be not working. Open an issue if you find one.

## Development
If you want to help to develop Solve my forms. Please make a fork of this repo, and:
1. Download node.js
2. Run ``npm i`` at the root of the repo
3. Use ``npm run build`` to build the extension
